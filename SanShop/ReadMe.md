> A beautiful, modern, lightweight **Point of Sale (POS)** and **Shop Management System** built using **HTML, Tailwind CSS, and Vanilla JavaScript**.

Designed for grocery stores, mini markets, tea shops, bakeries, supermarkets, and small businesses.

---

* Fast product selection
* Search products instantly
* Category filters
* Quick Combo Packs
* Add Custom Items
* Quantity controls
* Manual total editing
* Automatic subtotal calculation

# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/SanStudio-Smart-Shop-Assistant.git
```

Open the project:

```bash
cd SanStudio-Smart-Shop-Assistant
```

Run:

```
Open index.html
```

No installation required.

No server required.

Runs completely in your browser.
