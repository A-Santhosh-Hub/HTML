# SanCode

SanCode is an web workspace for editing code, writing documents, working with spreadsheets, and using everyday productivity tools.

## Features

- **Code Editor** — Edit files with syntax highlighting, formatting, and live HTML preview.
- **Web Extractor** — Enter a website URL to view its HTML source.
- **Web Assets** — Discover and download images, SVGs, media, fonts, and other linked files.
- **Word Processor** — Create and edit rich-text documents.
- **Spreadsheet** — Work with data in a table-based editor.
- **Document Tools** — Generate and manage PDFs.
- **Notes & Tasks** — Save notes and organize tasks with reminders.
- **Extra Tools** — QR codes, media player, code snippets, contact links, and text utilities.

## Installation

 1. Click and open SanCode.

## Offline Support

Core editing tools work offline. Website extraction and online media require internet access.

Web tools support publicly accessible content. Login-protected pages, bot protection, and dynamically loaded assets may limit results.
